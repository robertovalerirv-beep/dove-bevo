Il bottone di Dove bevo è un oggetto fisico: bordo `ink`, ombra `shadow-stampa`, e quando lo premi scende di 3px.

- `db-btn db-btn--primary`: una sola volta per schermata, per l'azione principale ("Segna un prezzo", "Salva"). Fondo `spritz`, testo `on-spritz`.
- `db-btn`: azioni secondarie ("Confermo", "Indicazioni").
- `db-btn--ghost`: azioni minori in forma di link ("È cambiato", "Segnala un errore"), in `spritz-text`.
- `db-btn--block`: larghezza piena nei fogli dal basso.
- Altezza minima 52px, testo in `label`. Etichetta sempre testuale; l'icona è facoltativa e decorativa.
- Focus: anello `focus` da 3px a 2px di distanza.
