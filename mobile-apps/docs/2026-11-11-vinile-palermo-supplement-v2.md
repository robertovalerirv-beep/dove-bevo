## Immutable import behavior

The importer stores approved sources as immutable rows keyed by source ID. Because the supplemental page-evidence digest differs from the first batch, reusing the first source ID would conflict with its existing source row. This manifest uses a new source ID, src-vinile-palermo-supp-c82fd401193a, even though both snapshots point to the same exact PDF URL and raw file hash. The database allows multiple source IDs for one URL; the new offer IDs are unique. The importer skips inserting the existing osm_static venue row, checks current public identity before any write, rejects non-identical rows with reused IDs, and inserts only absent source/offer rows. A local in-memory test applied the first 75 and then the 109 supplement rows: two source rows and 184 offers; a repeated supplement apply returned only existing_identical outcomes. This is a code-path test, not a protected provider dry run.
